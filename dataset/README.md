# Dataset directory

`raw/` holds input network-flow CSV files and `processed/` receives cleaned data generated by the notebook. The package includes `cicids2017_sample.csv`, a five-row structural sample extracted from the executed notebook output. It is included for schema inspection only and is not large enough for model training.

For a full run, add CICIDS2017 as `raw/cicids2017_smoke.csv` and CSE-CIC-IDS2018 as `raw/cic2018_smoke.csv`, or change the paths in the notebook configuration cell. Do not commit restricted or very large source datasets to a public repository.
