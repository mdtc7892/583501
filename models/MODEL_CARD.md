# Model card

## Purpose

The framework compares six classical classifiers, a dense neural network and a soft-voting ensemble for binary network-intrusion detection in a banking-security context.

## Training and evaluation

- Primary internal dataset: CICIDS2017.
- External generalisation dataset: CSE-CIC-IDS2018.
- Internal split: 8,317 training, 1,782 validation and 1,783 test records.
- Selected features: 22.
- Imbalance treatment: balanced class weights.
- Selection criteria: F1 score and false-positive rate.

## Recorded outcome

All evaluated models achieved an internal test F1 of 1.000 on the notebook's smoke dataset. External results were substantially weaker: the recorded F1 scores ranged from 0.4875 to 0.5189 and false-positive rates were approximately 1.0. This divergence means the artefact demonstrates pipeline execution but does not establish production readiness.

## Limitations

The embedded run used smoke datasets. Performance must be verified using authorised full datasets, time-aware validation, drift monitoring and a deployment-specific operating threshold before banking use. Serialized binaries are deliberately generated by the notebook from the local training data rather than distributed as unverified artefacts.
